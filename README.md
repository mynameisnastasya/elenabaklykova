# Елена Баклыкова — сайт юриста по банкротству физических лиц

Статический одностраничный сайт без внешних библиотек и сборщика.

## Что уже есть
- адаптивный премиальный дизайн;
- первый экран с понятным позиционированием;
- сценарии обращения;
- этапы работы;
- блок о рисках и честных ограничениях;
- FAQ;
- SEO-мета-теги;
- GitHub Pages workflow.

## Что нужно подтвердить перед рекламным трафиком
1. Телефон / WhatsApp / Telegram для записи.
2. Город и географию работы.
3. Правовой статус и реквизиты специалиста, если их требуется указывать.
4. Формат и стоимость первичной консультации.
5. Реальные подтверждаемые факты: опыт, кейсы, образование — только если их можно документально подтвердить.

## Публикация
Workflow лежит в .github/workflows/pages.yml и публикует main через GitHub Pages после включения Pages → Source: GitHub Actions в настройках репозитория.
